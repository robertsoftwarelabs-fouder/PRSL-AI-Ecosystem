# Architecture Documentation

This directory contains canonical architectural documents for the PRSL-AI ecosystem.

Architecture documents define system boundaries, ownership, responsibilities, principles, and target relationships.

```text
Architecture
   ↓
Design
   ↓
Implementation
   ↓
Validation
```

A documented architecture is not automatically an implemented capability. Repository evidence remains the authority for implementation status.

Apple-specific architecture is maintained separately under `Documentation/Apple-Integration/`.
