# PRSL-AI Apple Intelligence Architecture

## Purpose

Apple Intelligence is treated as an Apple system intelligence capability and integration surface within PRSL-AI, not as the owner of the ecosystem's intelligence architecture.

```text
Human
  ↓
Apple System
  ↓
Apple Intelligence
  ↓
Apple Integration Layer
  ↓
@iRiel Core
  ↓
Context + Identity + Policy
  ↓
Router
  ↓
Selected Capability / Intelligence
```

## Architectural Position

Apple Intelligence belongs behind the Apple Integration boundary. Canonical identity, context, memory, privacy, orchestration, routing, and capabilities remain owned by PRSL-AI.

## AI-Agnostic Principle

```text
Apple Integration
        ↓
iRiel Core
        ↓
Router
        ↓
On-Device / Local / Apple / OpenAI / Anthropic / Google / MCP / API / Tool
```

Using an Apple intelligence capability must not create an architectural dependency on a specific model provider.

## Context

Apple system context may enter PRSL-AI through controlled adapters:

```text
Apple Context Signals
      ↓
Apple Adapter
      ↓
Context Founder
      ↓
Unified Context
```

Context is interpreted by iRiel rather than delegated wholesale to the platform.

## Privacy

Apple exposure remains subject to PRSL-AI privacy and authorization policy.

```text
Canonical Data
      ↓
Privacy Policy
      ↓
Exposure Policy
      ↓
Apple Projection
```

Capability does not imply authorization.

## Objective

Apple Intelligence should reduce friction between the human and @iRiel while preserving canonical domain ownership, contextual continuity, privacy, and provider independence.

**Apple Intelligence is an integration capability. @iRiel remains the personal intelligence environment.**
