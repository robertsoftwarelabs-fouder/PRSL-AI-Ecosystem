# Apple Developer Forums Research

## Purpose

This file records relevant technical findings, observations, questions, and implementation evidence gathered from Apple Developer Forums.

Forum discussions are treated as **supporting technical evidence**, not as canonical specifications.

---

## Research Scope

Relevant areas include:

* Apple Intelligence
* Siri
* App Intents
* AppEntity
* EntityQuery
* IndexedEntity
* Spotlight
* App Schemas
* Contextual UI
* App Intents framework behavior
* Entity resolution
* System integration
* Accessibility
* Platform and SDK compatibility

---

## Evidence Classification

Forum findings should be classified as:

```text
Observed
Reported
Discussed
Experimental
Validated
Unverified
Resolved
```

A forum response should not be treated as authoritative solely because it comes from a participant with apparent platform expertise.

---

Future findings should preferably follow this structure:

---

## Source Reliability

Forum information should generally be evaluated against:

```text
Official Apple Documentation
        ↓
WWDC Technical Material
        ↓
Observed Platform Behavior
        ↓
Apple Developer Forums
```

When a forum discussion contradicts official documentation, the discrepancy should be explicitly recorded and independently verified.

## Research Discipline

Forum findings should not be copied directly into canonical architecture documents without analysis.

The preferred flow is:

```text
Forum Discussion
      ↓
Technical Observation
      ↓
Independent Verification
      ↓
Finding
      ↓
Architectural Analysis
      ↓
Canonical Documentation
```

## Architectural Impact

```text

```

## Maintenance

This file should evolve as Apple platform behavior changes.

When a finding becomes obsolete:

```text
Current Finding
      ↓
Platform Change
      ↓
Revalidation
      ↓
Updated Finding
```

Historical findings should be preserved when they provide useful architectural context.
